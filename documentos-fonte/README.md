# Acervo local de documentos-fonte

Esta pasta existe para organizar cópias locais de documentos públicos que fundamentam regras acadêmicas. O conteúdo real desta pasta é ignorado pelo Git; apenas este arquivo é versionado.

## O que guardar aqui

- PPCs oficiais;
- resoluções ConsEPE;
- atos decisórios da Comissão de Graduação;
- documentos oficiais de transição entre matrizes;
- catálogos e tabelas oficiais;
- normas de estágio, TCC, extensão e atividades complementares quando necessárias.

Não guardar históricos de estudantes, RA, notas, credenciais, tokens ou outros dados pessoais.

## Estrutura local sugerida

Crie no seu PC, conforme necessário:

```text
documentos-fonte/
├── ppcs/
│   ├── bct/
│   ├── bcc/
│   └── ...
├── resolucoes/
├── atos_decisorios/
├── transicoes/
├── catalogos/
└── normas_complementares/
```

Os PDFs são cópias de referência. A regra usada pelo sistema deve continuar estruturada no código/dados, com rastreabilidade para a fonte oficial, versão, data de consulta e estado de revisão.

Minutas e versões não normativas podem ser preservadas para auditoria, mas devem ser identificadas explicitamente como não normativas e nunca tratadas como regra vigente.
