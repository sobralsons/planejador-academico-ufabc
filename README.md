# 🎓 Planejador Acadêmico UFABC

Aplicação desenvolvida em Python para auxiliar estudantes na escolha de disciplinas e montagem da grade acadêmica.

## 📌 Problema

O planejamento de matrícula pode exigir a comparação manual de diversas informações, como:

- disciplinas disponíveis;
- conflitos de horário;
- créditos;
- histórico acadêmico;
- disciplinas obrigatórias;
- opções limitadas;
- preferências de horários;
- intervalos entre aulas.

Analisar todas essas combinações manualmente pode ser trabalhoso e nem sempre leva à melhor escolha.

## 💡 Solução

O sistema recebe informações acadêmicas e preferências do usuário, processa diferentes combinações de disciplinas e apresenta opções de grade avaliadas segundo diferentes critérios.

Entre os critérios considerados estão:

- conflitos de horário;
- quantidade de créditos;
- prioridade de disciplinas;
- intervalos entre aulas;
- progresso acadêmico;
- preferências definidas pelo usuário.

## ⚙️ Tecnologias

- Python
- Pandas
- Streamlit
- JSON
- Algoritmos de busca e avaliação
- Tratamento de dados

## 🖥️ Interface

A aplicação possui uma interface desenvolvida em Streamlit para facilitar o preenchimento das preferências e a visualização das grades sugeridas.
